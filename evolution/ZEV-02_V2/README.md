# ZEV-02 / ZhiNao V2: Internal State Enters the Reaction Conditions

**Evidence status: E1 / historical reconstruction**

This entry records the second stage in the public reconstruction of the ZhiNao engineering evolution. It is a stage-level research record, not a separately archived or independently validated V2 software release.

## The question

Why can the same external stimulus lead to different reactions at different times?

A pure stimulus-response description cannot explain that difference. V2 therefore asks whether an internal state must become part of the reaction conditions.

## What the V2 record adds

The project stage record describes a transition from:

```text
stimulus
-> bounded reaction
```

to a question that includes the system's current internal condition:

```text
stimulus + internal state
-> bounded reaction
```

This is a high-level description of the stage question. It does not disclose an internal state schema or claim that a complete V2 implementation has been independently recovered.

## What this stage does not establish

- consciousness;
- learning or memory as a validated capability;
- autonomous goals or values;
- AGI;
- the capabilities of later private ZhiNao generations.

## Why V3 became necessary

Once internal state is treated as part of the reaction conditions, the next question is how consequences return to influence later reactions. The project sequence records that question under V3.

## Disclosure boundary

This release contains only the high-level research question, the E1 evidence label and the public relation to V1 and V3. It does not include private kernel code, state schemas, scoring rules, thresholds, runtime traces, provider integrations or later-generation implementations.
