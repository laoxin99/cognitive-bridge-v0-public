# ZEV-11 / ZhiNao V11: Basic Adaptation in a Limited Markov Environment

**Evidence status: E2 / stage-report evidence**

This entry is a public summary of a dated V11 stage report. It is not a release of the V11 source tree or private runtime.

## The question

In a limited Markov simulation environment, can prediction, online behavior adjudication and structured weight migration form a workable basic adaptive system? Does experience reuse add a detectable advantage in that setting?

## What the stage report supports

- The report uses a single-seed long run, multi-seed validation and A/B comparison as three complementary checks.
- In the bounded Markov environment, prediction, online behavior adjudication and structured weight migration form a workable basic adaptive system.
- In the current one-step Markov decision framework, the experience-reuse mechanism does not show a significant additional survival advantage.
- The report therefore moves the value question for experience reuse to non-Markov, delayed-penalty or hidden-state environments.

## What this stage does not establish

- general-purpose learning or general intelligence;
- consciousness, memory as a universal capability or autonomous values;
- production autonomy or safety certification;
- that V3-V10 have been independently published or completed;
- that the unmerged structural-damage design is part of the current release.

## Why V12 became necessary

The V11 result is bounded by the Markov environment. The next question is whether contextual memory and experience reuse have a distinguishable value when relevant information is not fully contained in the current state.

## Disclosure boundary

This release contains only the stage-level conclusions supported by the report. It does not include source code, private state schemas, scoring rules, thresholds, runtime traces, provider integrations or private logs.
